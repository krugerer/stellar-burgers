# StellarBurger

Веб-приложение для создания и оформления заказов бургеров.

Проект разработан на React + TypeScript. Пользователь может собирать бургер из доступных ингредиентов, просматривать состав и стоимость заказа, взаимодействовать с модальными окнами и оформлять заказ.

## Возможности

* просмотр доступных ингредиентов через API;
* добавление ингредиентов в конструктор бургера;
* изменение состава заказа;
* автоматический расчёт стоимости;
* просмотр информации об ингредиентах;
* оформление заказа;
* работа с модальными окнами;
* обработка API-запросов;
* тестирование основных пользовательских сценариев;
* мокирование API-запросов в интеграционных тестах.

## Установка и запуск

Клонировать репозиторий:

```bash
git clone <ссылка-на-репозиторий>
```

Перейти в директорию проекта:

```bash
cd stellar-burgers
```

Установить зависимости:

```bash
npm install
```

Запустить проект в режиме разработки:

```bash
npm run dev
```

После запуска приложение будет доступно по адресу, который выведет Vite в терминале.

## Тестирование

Для запуска unit-тестов:

```bash
npm run test
```

Для запуска интеграционных тестов:

```bash
npx playwright test
```
